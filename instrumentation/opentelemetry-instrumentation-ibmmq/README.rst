OpenTelemetry IBM MQ Instrumentation
=====================================

|pypi|

.. |pypi| image:: https://badge.fury.io/py/opentelemetry-instrumentation-ibmmq.svg
   :target: https://pypi.org/project/opentelemetry-instrumentation-ibmmq/

This library allows tracing IBM MQ messages produced and consumed by the ibmmq and pymqi clients.

Installation
------------

::

    pip install opentelemetry-instrumentation-ibmmq
